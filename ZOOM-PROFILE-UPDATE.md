# Zoom display name registration

- My Courses now shows a prominent warning for students without a saved Zoom display name.
- The setup dialog explains Zoom sign-up and how to find/edit a Zoom name.
- The server validates and stores names, rejects duplicates, and refuses to release Zoom join URLs until a name is registered.
- Existing enrollment and class-time checks remain.
- Zoom Free Waiting Room admission is still manual: names can be impersonated, and meeting links can be shared.
